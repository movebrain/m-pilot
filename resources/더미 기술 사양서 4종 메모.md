## 공통 형식
- 목차: 1 일반 / 2 개요·모델명 체계 / 3 사양 / 4 시스템 / 5 기계 / 6 전기·제어 / 7 안전·LOTO / 8 운전 / 9 에러 코드 / 10 점검·정비 / 11 트러블슈팅 / 12 예비품 / 부록
- 에러 코드 대역: 100번대 SRM, 200번대 RTV, 300번대 AGV, 400번대 Mini Loader, 500번대 입출고 스테이션(예약)
- 심각도 3단계: 상(즉시 정지, 현장 확인 후 수동 복구) / 중(작업 중단, 리셋·재배정으로 복구) / 하(경고, 작업 계속)
- 조치 구분 2가지: 고객사 조치 / 엔지니어 필요. 같은 에러가 24시간 내 5회 이상 반복되면 엔지니어 필요로 취급
- 9장 구성: 표 9-1 코드 구간, 표 9-2 심각도, 표 9-3 조치 구분, 표 9-4 에러 코드 일람
- 표 9-4 열: 코드 · 명칭 · 대상 모델 · 심각도 · 조치 구분 · 발생 조건·원인 · 조치
- 파라미터 번호: P-RTV-xxx / P-SRM-xxx / P-AGV-xxx / P-MLD-xxx
- 용어: "에러"로 통일 (알람·오류 쓰지 않음)
- 속도 단위: m/min 기본. AGV 속도와 SRM 포크 속도는 m/s 병기
- 운전 모드 이름: 자동 / 반자동 / 수동 / 정비 / 티칭 (AGV만 개입 모드 추가)
- 사양표 항목 ID(DRV-02 등)는 AGV에만 있음

## 심각도 변환 기준 (원래 등급 → 상·중·하)
- RTV·Mini Loader: 중 → 상 / 경 → 중, 감속·표시만 하는 것은 하
- SRM: FATAL → 상 / ERROR 중 현장 수동 조치가 필요한 것 → 상, WCS 재배정·자동 복구 → 중 / WARN → 하
- AGV: FATAL·CRITICAL → 상 / URGENT → 중 / WARNING → 하
- AGV 조치 구분은 리서치의 조치 주체 기준: 정비원 → 엔지니어 필요, 작업자·모니터링 담당자·자동 → 고객사 조치

## RTV
- 모델 7종: RTV-S10 / S15 / S30(직선), RTV-L10 / L15(루프), RTV-SY10 / SY15(싱크로)
- 근거: 공개 정보(현대무벡스 RTV 페이지, 2025 카탈로그)는 정의, 3형식, 절대위치 센서, 대차 간 통신, "컨베이어 대비 최대 20배"뿐. 수치는 모두 가상값이며 경쟁사 공개 사양 범위 안에서 설정 (Daifuku STV 200 m/min·1~3 t, Muratec 250 m/min, Addverb RGV 1.5 t·0.5 m/s²)
- 부록: A 파라미터, B 처리 능력 계산, C S/W 버전별 변경사항, D 보증
- RTV에만 있는 테스트 요소
  - 개정·버전에 따라 다른 값: L10 공차 속도 240 → 250 m/min(OBC v3.1 이상), 휠 슬립 임계 8% → 5%(OBC v3.2), 루프형 휠 점검 3개월 → 1개월(Rev.2.1)
  - 교차 참조: "11.1절 참조", "표 3-2 ~ 3-4" 등
  - 계산형 질문: 최소 차간거리 D = v·0.15 + v²/(2a) + 1.0 (표 4-3), S10 30 m 사이클 45.75 s / 약 67 팔레트/h (부록 B)
  - 조합 제약: S30은 C+B만, SY는 B만, K는 60 m 이하, F와 N 조합 불가

## SRM
- 구성 3종: SRM-P 팔레트형(1,000 kg, 20 m, 더블 마스트), SRM-B 버킷형(300 kg, 15 m, 240 m/min), SRM-S 싱글 마스트형(500 kg, 12 m)
- 근거: SRM 파트 `SRM_기술사양서_자동차물류`(v1.0)와 `SRM_연동사양서_자동차물류`의 기본 사양·기능 코드(CMD·RSP·STS·MOD·SNS·SAF)·에러 E101~E110을 그대로 사용. E111~E150과 모터·자중·로프·점검·예비품 값은 가상값
- 4.5절 입출고 스테이션 인계: 스테이션 상태, 정지 허용 오차(RTV ±5 / AGV ±10 mm), 타임아웃(수령 확인 3 s, 구역 허가 20 s)
- 없는 모델 테스트: 5,000 kg 중량형, 랙 높이 25 m 초과 사양은 "적용 대상 아님"

## Mini Loader
- 모델 3종: ML-S50(싱글 사이드 포크 50 kg), ML-T30(트윈 30 kg × 2, 300 m/min), ML-T50(트윈 50 kg × 2)
- 근거: 공식 페이지(고감속·Slip Zero, 경량 마스트, Twin Side Forking Device) + 특허 KR 10-2174172 B1(2대 운행 간섭 판단, R1 감속 / R2 정지) + 손재호 조사 보고서. ML-T50 수치는 손재호 보고서의 가정값
- 4.3절 듀얼 운전 간섭 제어: R1 3.0 m 감속, R2 1.5 m 정지, R2 대기 10초

## AGV
- 모델 6종: 플랫바디 FB-C(컨베이어 1,000 kg) / FB-L(리프트 1,500 kg) / FB-O(전방향 1,000 kg), 공정 물류 LP-2T(잭업 리프트 2,000 kg) / FK-2T(포크리프트 2,000 kg) / CV-200(경량 컨베이어 200 kg)
- 근거: 정혜윤 초안(플랫바디 3종, 특허·VCS·인증) + AGV 리서치(LP·FK·CV, 명세 58항목, 에러 83개). 에러는 리서치 83개 + 초안 기반 7개 = 90개
- 명세 항목 ID(STR·DRV·NAV·LHD·PWR·SAF·CTL·COM·ENV·MNT·STD)를 6종 공통으로 사용. 표 9-4의 "관련 명세"와 연결
- 값 정리: VCS 동시 제어 "1식 표준 50대, 최대 200대", 충전 단자 기준온도 1차 60 °C / 2차 75 °C
- 없는 모델 테스트: 대형 AMR(2·5·10톤급, 개발 중)은 "적용 대상 아님"

## 테스트 요소 (4종 공통)
- 비슷한 모델끼리 값만 조금 다르게: SRM-P vs SRM-S, ML-T30 vs ML-T50, FB-L vs LP-2T, FB-C vs CV-200, RTV L10 vs L15
- 여러 쪽에 걸친 표: 상세 사양, 표 9-4 에러 코드 일람, 정기 점검표
