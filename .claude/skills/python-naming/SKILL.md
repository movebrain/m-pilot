# Python 네이밍 컨벤션

> 이 저장소(mpilot) 전용 규칙이다. 기준은 PEP 8이며, 표준에 없는 규칙은 새로 만들지 않는다.

## 먼저 확인: 이미 정해진 이름

**`docs/spec.md`의 4·5장(타입, 필드, 컬럼, 시그니처)에 정해진 영어 식별자는 그대로 쓴다.** 아래 규칙으로 바꾸지 않는다. 예: `repeat_flag`, `confirmed`, `ServiceCase`, `case_id`, `routing`.

- 새 이름을 짓기 전에 spec.md에 이미 있는지 먼저 본다.
- 문서에 없는 이름만 아래 규칙으로 짓는다. 새 용어가 필요하면 `intent-first` 스킬에 따라 한글 용어는 intent.md 용어집에, 영어 식별자는 spec.md 4·5장에 먼저 추가하고 쓴다.

## 규칙

| 대상 | 형식 | 예 (이 저장소) |
| --- | --- | --- |
| 모듈·파일 | `lower_snake_case`, 짧게 | `errorcodes.py`, `routing.py`, `indexing.py` |
| 패키지(디렉터리) | `lowercase`, 밑줄 없이 | `src`, `ui` |
| 함수·메서드 | `lower_snake_case`, 동사로 시작 | `guide_for()`, `load_error_codes()` |
| 변수·인자 | `lower_snake_case`, 명사 | `case_brief`, `error_code` |
| 클래스·타입 | `CapWords` | `ServiceCase`, `CaseBrief`, `QueryAnalysis` |
| 상수 | `UPPER_SNAKE_CASE`, 모듈 최상단 | `MAX_PAIRS` (새 상수의 예) |
| 비공개 | 앞에 밑줄 하나 | `_build_prompt()` |

환경 변수 이름(`MPILOT_FAKES`)은 상수가 아니라 환경 변수 이름이다.

## 세부 기준

- **약어는 전부 대문자로 쓴다.** 클래스에서는 `AGVInfo`처럼 쓰고 `AgvInfo`는 쓰지 않는다. 함수·변수에서는 소문자 그대로 `agv_id`로 쓴다.
- **이름은 영어로 쓴다.** 한글 로마자 표기(`sinko`)나 한글 식별자는 쓰지 않는다. 도메인 용어의 영어 이름은 spec.md 4·5장을 따른다(접수 건 → `case`, 접수번호 → `case_id`).
- **새 `bool` 이름은 `is_`, `has_`, `can_`로 시작한다.** 예: `is_resolved`. 단, 위의 "이미 정해진 이름"은 접두가 없어도 그대로 쓴다.
- **내장 이름을 가리지 않는다.** `id`, `type`, `list`, `input` 대신 `case_id`, `kind` 등을 쓴다. 충돌이 불가피하면 `class_`처럼 뒤에 밑줄 하나를 붙인다.
- **한 글자 이름은 짧은 반복문 변수에만 쓴다.** `l`, `O`, `I`는 숫자 `1`, `0`과 헷갈리므로 쓰지 않는다.
- **기존 코드의 이름은 이 스킬 때문에 함부로 바꾸지 않는다.** 새로 짓는 이름에만 적용하고, 위반 이름이 보이면 알려주기만 한다.

## 의도 확인 (가이드 질문)

아래 상황에서 표준만으로 정해지지 않으면 추측하지 않고 `AskUserQuestion`으로 묻는다. 표준과 문서로 분명하면 묻지 않는다.

- **spec.md에 식별자가 없는 용어를 영어로 옮길 때**: spec.md 4·5장을 먼저 확인하고, 없는 용어만 후보 2~3개를 선택지로 제시해 묻는다.
- **외부 라이브러리·기존 이름과 충돌할 때**: Gradio, Chroma, DB 모델의 이름과 겹치면 어느 쪽에 맞출지 확인한다.
- **PEP 8과 spec·기존 코드 관례가 다를 때**: spec에 정해진 이름은 spec을 따르고, 그 밖에는 새 이름을 표준에 맞출지 기존 관례에 맞출지 확인한다.

## 하지 말 것

- spec.md에 정해진 식별자를 이 스킬의 규칙으로 바꾸기(`repeat_flag` → `is_repeat` 등)
- 표준에 없는 접두사·접미사 규칙(헝가리안 표기, 타입 이름을 변수명에 붙이기 등) 추가
- `camelCase` 함수·변수, `snake_case` 클래스
- `data`, `info`, `tmp`, `obj`처럼 뜻이 없는 이름
- 한글 로마자 표기, 한글 식별자
- `id`, `type`, `list` 같은 내장 이름 덮어쓰기
- 이름 규칙을 이유로 한 기존 코드의 대량 이름 변경
